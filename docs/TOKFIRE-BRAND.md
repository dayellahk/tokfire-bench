## Short English introduction

TokFire Bench by TokFire Labs shows how local AI models perform on your Mac.
Benchmark GGUF and MLX models, measure token speed and first-token latency,
and see what happens when several jobs call the same model at once.

## 繁體中文介紹

TokFire Bench 由 TokFire Labs 開發，幫你實測 Mac 運行本地 AI 模型嘅表現。
支援 GGUF 同 MLX，量度生成速度、首個 token 等待時間，同一模型多個 jobs
同時運行嘅表現。用真實數據，揀適合你部機嘅模型。

## Release copy

Free: choose 1, 2 or 3 simultaneous jobs on one model.
Pro: HK$180 once, up to 20 jobs on one model, one activated Mac per license.
Pro sales await merchant approval; do not advertise an active checkout yet.
The current Apple Silicon developer build requires Python and llama.cpp or
 oMLX, plus separately downloaded models. It is ad-hoc signed, not notarized.
No minimum token speed or 20-job hardware capacity is guaranteed.

## Upgrade compatibility

Display names, icons, app bundle and download filenames use TokFire Bench.
The existing bundle identifier, Keychain service, Application Support/LocalAIBench
storage and benchmark protocol IDs are retained so existing data remains usable.
The working Sites origin remains the native account/API endpoint until custom
hostname authentication has been verified. DNS configuration does not make the
currently private website publicly accessible.

TokFire Labs is the supplied brand/company name. Lemon Squeezy's legal merchant
identity is still Dayella Limited; changing legal business/tax records is a
separate seller-account action. The product is renamed TokFire Bench Pro.
